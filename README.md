# ByteFeed 🚀

O ByteFeed é uma rede social moderna, completa e escalável, projetada para conectar pessoas através de compartilhamento de conteúdo rápido e intuitivo.

## 📌 Sobre o Projeto

Este projeto é uma aplicação Full Stack que utiliza as tecnologias mais recentes do mercado para entregar uma experiência de usuário fluida e um backend seguro.

### Funcionalidades Principais
- 🔐 Autenticação segura com JWT.
- 📝 Criação, edição e exclusão de posts.
- 👤 Perfis de usuário personalizáveis.
- 📱 Design totalmente responsivo.

## 🛠️ Tecnologias

**Backend:** Java 21, Spring Boot 4, PostgreSQL, Spring Security (JWT), Liquibase.

**Frontend:** React 19, Vite, Tailwind CSS 4, React Router.
